## Notes

- The `id` vs `kind` distinction matters: `id` identifies the *implementation* (the key its body registers under), `kind` is the *type discriminator* that `openTab` names. The radio plugin sets both to `'radio'`; the reference snake sets both to `'snake'`. Here both should be `'auto-snake'`.
- Package name vs slot key: `plugins.bundle.config` is keyed by the **package name** (`dsh-auto-snake`), while `sidebar.right.pane.tab` is keyed by the **type id** (`auto-snake`).
- The host half (`index.js`) is correctly a no-op; this is a client-only bundle and `dsh.client` in `package.json` is what makes the Web shell load `client.js`.
